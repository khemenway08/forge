Version: 2.0
Status: Approved
Last Updated: 2026-07-13

## Purpose

Defines the official Forge user interface standards.

## Authority

This document is the authoritative source for all Forge user interface decisions.

## Dependencies

Forge.md

# 1. Brand Identity

Forge contains two distinct user experiences.

## Customer Experience

Brand:
The Hilltop Shop

Purpose:
Warm, welcoming, handcrafted, boutique.

The customer should feel like they are ordering a handcrafted product from a local Texas business.

---

## Staff Experience

Brand:
Forge

Purpose:
Industrial, efficient, focused.

The staff should feel like they are operating production software rather than shopping on a website.

---

# 3. Official Logos

Customer Interface

- Use only official The Hilltop Shop logos.

Staff Interface

- Use only official Forge logos.

Rules

- Never recreate logos with AI.
- Never substitute fonts.
- Always use official vector assets.

# 5. Typography

Use one font family throughout Forge.

Hierarchy

- Page Title
- Section Title
- Card Title
- Body
- Caption
- Button Text

Brand logos retain official typography.

---

# 6. Layout System

Primary Target

- iPad Landscape

Secondary

- Desktop

Responsive

- Mobile

Customer screens prioritize clarity over density.

---

# 7. Navigation

Customer

- Linear workflow
- One primary action per screen
- No unnecessary menus

Staff

- Dashboard
- Sidebar navigation
- Fast switching

---

# 8. Component Library

Approved Components

- Product Card
- Color Card
- Size Card
- Icon Card
- Person Card
- Pet Card
- Order Summary Card
- Customer Card
- Status Badge
- Primary Button
- Secondary Button

All screens should be assembled from approved components.

---

# 9. Product Cards

Display

- Product Photo
- Product Name
- Short Description
- Optional Price
- "Tap to Customize"

Selecting a product automatically advances to the next step.

---

# 10. Forms

Rules

- Auto-advance after selections.
- Auto-focus newly created fields.
- Single-column customer information.
- Large touch targets.

Disable

- Spell Check
- Auto Correct
- Auto Fill

---

# 11. Personalization

Order

1. Product
2. Size
3. Colors
4. Family Name
5. People
6. Pets

People and pets share one ordered list.

Customers may reorder names.

Forge preserves that order through production.

---

# 12. Product Preview

Whenever space allows:

Display the product image while customization is taking place.

Customers should always understand what they are ordering.

---

# 13. Review Screen

Receipt-style layout.

Display

- Product
- Options
- Family
- People
- Pets
- Customer
- Shipping

Staff Only

- Production Notes
- Internal Flags

Never expose database information.

---

# 14. Motion

Allowed

- Fade
- Slide
- Auto-scroll

Not Allowed

- Flashing
- Decorative transitions
- Large animations

Motion should support usability, never distract.

---

# 15. Accessibility

- Every icon includes a text label.
- Minimum touch target: 44px.
- Support keyboard navigation.
- Maintain accessible color contrast.

---

# 16. Responsive Behavior

Desktop

- Multi-column layouts

Tablet

- Primary experience

Phone

- Single-column
- Simplified navigation

---

# 17. UI Rules

Always Use

- Real product photos
- Official logos
- Image-based selection
- Large touch targets
- One primary action per screen

Never Use

- Long radio button lists
- Hidden required fields
- Multiple primary buttons
- Decorative effects

---

# 18. Future Components

New components should extend the existing design system.

Reuse existing interaction patterns before creating new ones.

---

# 19. UX Philosophy

Forge should feel effortless.

Rules

- The customer should never wonder what to do next.
- Every step should feel like a conversation.
- Product images should answer questions before text.
- Reduce typing whenever possible.
- Every screen should present one obvious primary action.
