# Backlog — Revision 1.1

## Added Version 1 Critical Feature

### Production Filtering
Priority: Critical
Status: Planned

Forge must provide searchable production filters generated from structured item attributes.

Required filters:

- Product
- Size
- Tree Color
- Bow Color
- Year
- Production Status
- Shipping / Pickup
- Event
- Open Flags

### Production Batch View

Forge should automatically group similar products together for efficient manufacturing.

Examples:

- 14 × Large Tree / Green / Red Bow
- 9 × Present Stack / White Bow
- 3 × Veteran Flag
- 2 × Custom Icon Requests
